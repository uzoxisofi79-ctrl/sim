## Подтверждение почты

**Заголовок:** Подтвердите электронную почту

**Текст:** Мы отправили письмо на адрес **{email}**. Перейдите по ссылке в письме, чтобы завершить регистрацию.

**Подсказка:** Если письмо не пришло, проверьте папку «Спам».

**Кнопка:** Отправить письмо повторно

**Сообщение после повторной отправки:** Письмо отправлено повторно. Проверьте почту.

**Сообщение при успешном подтверждении:** Почта подтверждена. Добро пожаловать в ЯНУШ.

## Восстановление пароля

### Шаг 1 — Запрос

**Заголовок:** Восстановление пароля

**Текст:** Укажите почту, привязанную к аккаунту. Мы отправим ссылку для сброса пароля.

| Элемент | Текст |
|---------|-------|
| Метка поля | Электронная почта |
| Плейсхолдер | name@example.com |
| Кнопка | Отправить ссылку |
| Ссылка | Вернуться ко входу |

**Сообщение после отправки:** Если аккаунт с такой почтой существует, мы отправили ссылку для сброса пароля.

### Шаг 2 — Новый пароль

**Заголовок:** Новый пароль

| Элемент | Текст |
|---------|-------|
| Метка поля | Новый пароль |
| Плейсхолдер | Не менее 8 символов |
| Метка поля | Подтверждение пароля |
| Плейсхолдер | Повторите пароль |
| Кнопка | Сохранить пароль |

**Сообщение при успехе:** Пароль изменён. Теперь вы можете войти с новым паролем.

**Ошибка — ссылка истекла:** Ссылка для сброса пароля истекла. Запросите новую.
