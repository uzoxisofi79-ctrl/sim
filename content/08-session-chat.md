# Сессия (чат с ИИ-учеником)

---

## Интерфейс чата

### Шапка сессии

| Элемент | Текст |
|---------|-------|
| Заголовок | Сессия |
| Индикатор доверия | Доверие: {значение}/100 |
| Индикатор стресса | Стресс: {значение}/100 |
| Тултип «Доверие» | Готовность подростка поддерживать контакт. Растёт при понимании, падает при давлении. |
| Тултип «Стресс» | Эмоциональное напряжение подростка. При критических значениях возможен экстремальный исход. |
| Кнопка | Завершить сессию |

### Область сообщений

| Элемент | Текст |
|---------|-------|
| Метка отправителя (педагог) | Вы |
| Метка отправителя (подросток) | {Имя подростка} |
| Системное сообщение (начало) | Сессия началась. Вы можете писать реплики или использовать невербальные действия. |
| Плейсхолдер поля ввода | Напишите реплику… |
| Кнопка отправки | Отправить |
| Тултип кнопки отправки | Отправить реплику (Enter) |

---

## Невербальные действия

**Заголовок выпадающей панели:** Невербальные действия

**Тултип кнопки:** Действия, которые не требуют слов: паузы, жесты, изменение позы

| Действие | Описание в чате (системное сообщение) |
|----------|--------------------------------------|
| Пауза | *Вы выдерживаете паузу* |
| Кивок | *Вы киваете* |
| Зрительный контакт | *Вы устанавливаете зрительный контакт* |
| Отвести взгляд | *Вы отводите взгляд* |
| Наклон вперёд | *Вы слегка наклоняетесь вперёд* |
| Откинуться назад | *Вы откидываетесь на спинку стула* |
| Предложить воду | *Вы предлагаете стакан воды* |
| Предложить салфетку | *Вы протягиваете салфетку* |
| Встать | *Вы встаёте* |
| Сесть рядом | *Вы пересаживаетесь ближе* |
| Открытые ладони | *Вы показываете открытые ладони* |

## Глобальные события (системные сообщения)

| Событие | Текст в чате |
|---------|-------------|
| Звонок телефона | *У {имя подростка} звонит телефон.* |
| Сообщение в мессенджере | *{Имя подростка} получает сообщение и смотрит на экран.* |
| Кто-то заглянул | *В дверь заглядывает другой ученик.* |
| Приход сотрудника | *В кабинет заходит {роль}.* |
| Шум за дверью | *За дверью раздаётся шум.* |
| Объявление | *По громкой связи звучит объявление.* |
| Звонок на перемену | *Звенит звонок на перемену.* |

---

## Экстремальные исходы (системные сообщения)

| Исход | Текст в чате |
|-------|-------------|
| Подросток уходит | *{Имя подростка} встаёт и молча выходит из кабинета. Сессия завершена.* |
| Агрессия | *{Имя подростка} проявляет агрессию: {описание}. Сессия завершена.* |
| Полный отказ | *{Имя подростка} замолкает и перестаёт реагировать на ваши слова. Сессия завершена.* |

**Сообщение при провале:**
Сессия завершена из-за экстремального исхода. Результаты и оценки экспертов доступны на экране результатов.

**Кнопка:** Перейти к результатам

---

## Диалог подтверждения завершения

**Заголовок:** Завершить сессию?

**Текст:** Диалог будет завершён, и вы перейдёте к экрану результатов. Продолжить беседу после этого нельзя.

| Кнопка | Текст |
|--------|-------|
| Основная | Завершить |
| Вторичная | Продолжить беседу |
