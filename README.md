## Тон и стиль

- Как умный коллега — без поучений, маркетинга и воды
- Профессиональный, конкретный, эмпатичный к педагогу
- Обращение на «вы»; без восклицательных знаков в заголовках
- Лёгкая ирония — только в совещательной комиссии
- Грамотный русский язык, без канцелярита и англицизмов
